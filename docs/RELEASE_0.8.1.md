# ReproCheck 0.8.1

Version 0.8.1 is a publication and packaging patch with no parser or audit
behavior change relative to 0.8.0.

- Adds project URLs, classifiers, citation metadata, contribution guidance, and
  a reproducibility index.
- Splits fast multi-version CI from the single full scientific gate.
- Adds a tag-driven release workflow that runs the full gate before publishing
  wheel and source archives.
- Preserves the frozen 0.8.0 evaluator and its development result unchanged.
