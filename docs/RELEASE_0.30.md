# ReproCheck 0.30.0

ReproCheck 0.30.0 adds Evidence Trial v19, a preregistered and fail-closed
three-arm workflow for comparing report-only review, supplied metrics, and raw
artifact recomputation on the same blinded ML claims.

The release adds strict protocol and sample schemas, immutable multi-artifact
registration, prior-owner and file exclusions, a minimum-information gate,
two-reviewer adjudicated gold locks, tri-state scoring, owner-cluster bootstrap,
exact McNemar tests with Holm correction, and a separate minimal-witness track.

The bundled offline demonstration covers supported, contradicted, and
not-verifiable outcomes and proves witness tamper rejection.

Scientific status at release: registered tooling and protocol, unexecuted
external trial. No v19 external performance or human-review result is claimed.
