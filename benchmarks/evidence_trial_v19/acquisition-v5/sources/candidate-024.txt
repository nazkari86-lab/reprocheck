# Model comparison and ablations

Use this page to document your **ablation results** (backbone × fusion) and to compare against YouTubePD and Figshare turning baselines.

## How to run ablations

From the project root:

```bash
# Face PD: 3 backbones × 2 fusion = 6 runs (~same data/split, seed=42)
python scripts/run_ablations.py --task face_pd --num_epochs 20

# Turning (video + audio + IMU): 6 runs
python scripts/run_ablations.py --task turning --num_epochs 20

# Both tasks
python scripts/run_ablations.py --task face_pd,turning --num_epochs 20
```

Results are written to:

- `results/ablation_face_pd.csv`
- `results/ablation_turning.csv`

Each row: `task`, `backbone`, `fusion`, `checkpoint`, `val_acc`, `val_f1`, `val_auroc`.

### Observations (Face PD)

- **Attention fusion outperforms concat** for ResNet18 on this split: Val AUROC 0.90 vs 0.83.
- **ResNet18** completed all 20 epochs; metrics above are from the best checkpoint (saved by AUROC), not necessarily the final epoch.
- **EfficientNet (B0, B2)** runs **failed with OOM** even with batch_size=2: either killed with exit code -9 (SIGKILL) after epoch 1, or failed in epoch 2 with “DataLoader worker is killed by signal: Killed”. So on this machine (limited RAM/GPU), EfficientNet ablations could not be completed; consider running them on a machine with more memory or with batch_size=1 and num_workers=0.
- All runs use the same train/val split (seed=42) for fair comparison.
- Summary: among completed runs, **ResNet18 + attention** is the best Face PD model (Val AUROC 0.90).
