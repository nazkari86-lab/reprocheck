# Frozen cross-repository challenge corpus

This corpus was selected after ReproCheck 0.5.0 was frozen and before its
zero-shot result was measured. Selection is exhaustive inside two declared
official-repository path patterns:

- Detectron2 `MODEL_ZOO.md`;
- all 113 MMDetection `configs/*/README.md` files.

The corpus targets AP, AR, PQ, box/mask, Markdown-table, and HTML-table result
formats that are underrepresented in the original three-repository study. It is
not independently annotated ground truth. Labels are generated by a separate,
documented table rule and must be described as rule-derived internal labels.

## Results

| Evaluator | Scientific phase | TP | FP | FN | Precision | Recall |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 0.5.0 frozen wheel | zero-shot, before inspection | 18 | 0 | 988 | 100.00% | 1.79% |
| 0.6.0 wheel | development after inspection | 1,006 | 2 | 0 | 99.80% | 100.00% |

The v0.5 recall Wilson 95% interval is 1.13%-2.81%. The v0.6 strict precision
interval is 99.28%-99.95%, and its recall interval is 99.62%-100%. The v0.6
result is not a held-out generalization estimate because implementation changed
after the corpus was inspected.

The two strict v0.6 false positives are the spelled-out headers
`bbox detection Average Precision` and `segmentation Average Precision` in the
DeepFashion file. One internal post-hoc review classifies them as valid claims
omitted by the frozen abbreviation-only annotation rule. The primary 1,006-label
score remains unchanged, and there are still zero independent external
reviewers and no adjudication.

## Reproduction

```bash
python3 benchmarks/challenge_artifacts/fetch_sources.py --fetch
python3 benchmarks/challenge_artifacts/fetch_sources.py
python3 benchmarks/challenge_artifacts/build_annotations.py
python3 benchmarks/challenge_artifacts/check_results.py
make challenge-replay
```

The first command is the only networked operation. Normal verification fails on
missing, extra, size-mismatched, or SHA-mismatched files. Source copies remain
under their upstream licenses.

`zero-shot-v0.5.json` is the original immutable result. The v2 frozen replay
uses an explicit table-only scope and reproduces the same summary. Both stored
wheels are installed into temporary environments, bound through
`direct_url.json`, and must reproduce their saved v2 JSON byte for byte.

## Validity boundary

This challenge establishes a documented parser failure and verifies that the
implemented format support resolves every frozen labelled case. It does not
establish state-of-the-art extraction, independent annotation agreement, or
performance on unseen repositories. A preregistered repository holdout with
two independent annotators and blinded adjudication is still required for an
external generalization claim.
