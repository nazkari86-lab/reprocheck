# 경상권 중심 관광지 벤치마크 확장 결과

## 수집 조건

- 중심 관광지 기준월: 2025년 3월(`202503`)
- 관광자원 수집일: 2026년 8월 4일
- 1차 대상: 경상권 12개 기초지자체, 지역별 3개, 총 36개
- 유형 보강 대상: 실제 중분류 `자연관광`, `레저스포츠` 각각 6개
  지역·지역별 2개·총 12개
- 반경: 1km, 2km 직선거리
- 중심 관광지 필터: 대분류 `관광지`, 중분류 `쇼핑` 제외
- 보완 자원: 음식점, 숙박, 문화시설, 행사/공연/축제, 쇼핑

KorService2 시군구 코드는 분석 전에 `areaCode2`의 공식 코드명과 자동
대조했다. 12개 지역이 모두 검증을 통과했으며 API 호출 실패 지역은 없다.
유형 보강 분석도 각 6개 지역이 코드 검증을 통과했고 실패는 없다.

## 표본 지역

| 수집 표본군 | 지역 |
|---|---|
| 역사문화형 | 경주시, 안동시, 진주시 |
| 해양관광형 | 포항 북구, 통영시, 거제시 |
| 도시관광형 | 부산 중구, 대구 중구, 울산 남구 |
| 자연산악형 | 영주시, 문경시, 산청군 |

표본군은 지자체의 성격을 기준으로 한 수집 층이다. 실제 관광지 유형은 중심
관광지 API의 중분류를 사용해야 한다.

## 실제 관광지 중분류 구성

| 실제 중분류 | 표본 수 | 벤치마크 사용 가능 여부 |
|---|---:|---|
| 역사관광 | 14 | 가능 |
| 문화관광 | 13 | 가능 |
| 기타관광 | 7 | 사용 보류: 세부 성격이 이질적이고 소분류가 비어 있음 |
| 레저스포츠 | 12 | 가능: 실제 중분류 지정 보강 표본 |
| 자연관광 | 12 | 가능: 실제 중분류 지정 보강 표본 |

`자연산악형` 지자체에서 뽑은 관광지 9개 중 6개가 실제로는 역사관광으로
분류됐다. 따라서 지자체 표본군을 관광지 유형 벤치마크로 직접 사용하면 안
된다. 이 분석에서는 같은 실제 중분류 표본이 8개 이상일 때만
`benchmark_ready=true`로 표시했다.

자연관광은 경주·진주·포항 북구·통영·거제·영주, 레저스포츠는
경주·안동·진주·포항 북구·통영·문경에서 실제 중분류를 먼저 지정한 뒤
각 지역 상위 2개를 수집했다. 이는 원래 36개 표본에서 같은 관광지가 다시
포함될 수 있으므로, 표본 수를 단순히 합산하지 않고 유형별 보강 결과 12개를
해당 유형의 분포로 사용했다.

## 1차 해석

1. 경상권 전체를 하나로 합친 P25는 대부분 0이어서 빈칸 기준으로 사용하기
   어렵다.
2. 같은 중심 관광지라도 도시 문화관광지와 외곽 역사관광지의 주변 자원
   구조가 크게 다르다.
3. 역사관광은 행사와 쇼핑이 없는 경우가 절반 이상이다. 이 두 항목의 0개를
   곧바로 전체 체류 빈칸으로 판정하면 우수 관광지 다수가 빈칸이 된다.
4. 음식점은 역사·문화관광에서만 2km P25가 0보다 크다. 자연관광과
   레저스포츠에 같은 음식점 기준을 적용하면 유형 차이를 빈칸으로 오인한다.
5. P25가 0인 항목은 P25 미달 규칙을 적용할 수 없다. 0개 비율과 중앙값을
   함께 보거나 정책적 최소조건을 별도로 둬야 한다.
6. 자연관광은 우수 사례에서도 숙박·문화·행사·쇼핑의 과반이 0개다. 현재
   공급 데이터만으로는 이 항목들의 `0개`를 서비스 빈칸으로 정의할 근거가
   없다.
7. 레저스포츠는 개별 항목 P25가 모두 0이지만, 여러 유형을 합친 총 보완
   자원과 유형 충족 점수는 P25가 0보다 크다. 이 유형은 종합지표가 개별
   항목보다 안정적인 후보이다.

## 서비스 기준 후보

아래 기준은 값을 P25 **미만**으로 판정했을 때 정수 데이터에 대응하는
임시 하한이다. 아직 전국 표본이나 실제 체류시간으로 검증한 운영 기준은
아니다.

| 실제 유형 | 2km 경험적 하위 기준 후보 | 현재 적용하지 않을 항목 |
|---|---|---|
| 역사관광 | 음식점 1개 이하, 숙박 0개, 유형 충족 20점 이하 | 행사·쇼핑 단독 0개 |
| 문화관광 | 음식점 1개 이하, 유형 충족 20점 이하 | 숙박·문화·행사·쇼핑 단독 0개 |
| 자연관광 | 없음: 모든 핵심 P25가 0 | 각 항목의 0개 및 종합점수 0점 |
| 레저스포츠 | 총 보완 자원 1개 이하 또는 유형 충족 0점 | 개별 항목의 0개 |

실제 판정에서는 한 지표만으로 `빈칸`을 확정하지 않고 우선
`benchmark_gap_candidate`로 표시하는 편이 안전하다. 특히 유형 충족 점수는
개별 항목 존재 여부에서 파생되므로 음식점·숙박 개수와 독립된 증거로
간주하면 안 된다. 자연관광은 거리보다 이동시간 접근성이나 관광지 내부
시설 데이터가 더 적합한지 추가 검토해야 한다.

## 다음 표본 수집 권장사항

- 기타관광은 교량·여객터미널·마을·모노레일 등이 섞여 있으므로 수동 또는
  외부 분류 체계로 동질적인 세부 유형을 만든 뒤에만 벤치마크한다.
- 역사관광과 문화관광도 각각 20개 이상으로 확장한 후 P25를 다시 계산한다.
- 한 지역의 밀집 관광지가 여러 개 포함된 경우 지역 효과가 과대 반영되므로
  지역당 표본 수를 동일하게 유지한다.
- 레저스포츠 12개 중 골프장이 4개이므로 세부 유형별 편향을 확인한다.
- 최종 빈칸 규칙은 경험적 벤치마크와 정책적 최소조건을 분리한다.
- `benchmark_gap_candidate`와 실제 체류시간·재방문율의 관계를 검증한 뒤
  운영 임계값으로 승격한다.
