# ReproCheck numeric-mutation experiment v2

Status: **completed constructed-mechanism experiment; not human-gold accuracy**.

## Research question

Can ReproCheck detect that an evidence passage preserves almost all surrounding text but
contains a substituted numerical result?

The corrected v2 protocol, code, new seed, owner split, baselines, and test policy were
registered and pushed before the test was executed. Registration SHA-256:
`ec845d7dc68d3324bacb7394e955d7d4b937079bc5033b3d42d6d414f45292d5`.

## Frozen test results

The test set contains 150 balanced pairs from previously unseen owners.

| Method | Precision | Recall | F1 | AUROC | Brier |
|---|---:|---:|---:|---:|---:|
| Number-normalized lexical overlap | 0.500 | 1.000 | 0.667 | 0.500 | 0.5000 |
| Text-only sparse logistic | 0.500 | 0.853 | 0.631 | 0.496 | 0.2500 |
| Hybrid numeric-consistency + sparse logistic | **0.933** | **0.933** | **0.933** | **0.960** | **0.2164** |

For the hybrid model, the 1,000-sample owner-level bootstrap 95% interval was
`[0.865, 0.979]` for F1 and `[0.906, 0.991]` for AUROC. The hybrid made 70 true-positive,
70 true-negative, 5 false-positive, and 5 false-negative decisions.

## Ablation conclusion

Removing the explicit numeric-consistency feature reduced test F1 from 0.933 to 0.631
and AUROC from 0.960 to 0.496. Number-normalized lexical similarity also remained at
chance AUROC. The result supports the engineering hypothesis that ReproCheck should be a
hybrid system: deterministic source binding supplies exact consistency features, while ML
combines them with textual context.

## Preserved failed experiment

V1 encoded the consistency level with a number. The common text normalizer erased that
number, so hybrid and text-only models were equivalent and both reached F1 0.6435. V1 is
preserved in `data/mutation-experiment-v1`; `mutation-amendment-1.md` explains the defect.
V2 used a new seed and split instead of rerunning the opened V1 test.

## Limitations

- Negative evidence is generated by a controlled numeric substitution.
- The hybrid feature directly measures the constructed mutation mechanism.
- The experiment establishes mechanism sensitivity, not accuracy on naturally occurring
  scientific-report errors.
- Independent human annotation, adjudication, hidden gold evaluation, and prospective
  evaluation remain required.
