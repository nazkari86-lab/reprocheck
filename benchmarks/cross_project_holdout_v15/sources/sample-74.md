# 课程设计报告大纲

## 题目

基于 scikit-learn 的工业蒸汽量预测模型设计与对比分析

## 1. 研究背景与意义

- 工业生产过程中蒸汽量预测对能源调度、生产优化和成本控制具有重要意义。
- 蒸汽量通常受多个工艺参数影响，适合使用监督学习回归模型进行预测。
- 本课程设计基于阿里云天池“工业蒸汽量预测”数据集，使用 scikit-learn 对多个回归模型进行训练和对比分析。

## 2. 数据集介绍

- 数据来源：阿里云天池“工业蒸汽量预测”竞赛。
- 数据类型：结构化表格数据。

- 目标变量：`target`，表示工业蒸汽量。
- 任务类型：监督学习中的回归预测任务。

## 4. 数据预处理方法

### 4.1 数据加载

使用 `pandas.read_csv` 读取训练集和测试集，自动兼容逗号、制表符和空格分隔。

### 4.2 特征与标签划分

- 特征矩阵：去除 `target` 列后的所有列；
- 目标变量：`target` 列。

### 4.3 训练集与验证集划分

使用 `train_test_split` 将训练数据划分为训练集和验证集，验证集比例设为 20%。

### 4.4 缺失值处理

对数值特征使用中位数填充：

```python
SimpleImputer(strategy="median")
```

### 4.5 标准化处理

使用 `StandardScaler` 对特征进行标准化，使不同量纲的特征具有可比性。

### 4.6 Pipeline 封装

使用 `Pipeline` 将数据预处理和模型训练统一封装，避免验证集信息泄露到训练阶段。

## 5. 模型设计

本实验选择四种回归算法：

### 5.1 LinearRegression 线性回归

- 优点：结构简单、训练速度快、可解释性强。
- 缺点：难以拟合复杂非线性关系。

### 5.2 DecisionTreeRegressor 决策树回归

- 优点：能处理非线性关系，模型直观。
- 缺点：容易过拟合，泛化能力可能不稳定。

### 5.3 RandomForestRegressor 随机森林回归

- 优点：通过集成多棵树降低方差，鲁棒性较好。
- 缺点：模型规模较大，可解释性弱于单棵树。

### 5.4 GradientBoostingRegressor 梯度提升回归

- 优点：逐步拟合残差，适合结构化数据回归任务。
- 缺点：参数较敏感，训练时间通常长于简单模型。

## 6. 评价指标

由于任务为回归预测，选择以下指标：

- MAE：平均绝对误差，反映平均预测偏差；
- MSE：均方误差，对大误差更敏感；
- RMSE：均方根误差，与目标变量量纲一致；
- R²：决定系数，反映模型对目标变量方差的解释能力。
